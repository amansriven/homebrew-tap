# amansriven/homebrew-tap

Command line only:

```bash
brew install amansriven/tap/sticky
```

The Mac app and the command line (name both, so Homebrew trusts both):

```bash
brew install amansriven/tap/sticky amansriven/tap/sticky-app
```

| Name | Type | What it does |
|---|---|---|
| [sticky](https://github.com/amansriven/Sticky) | Formula | Find out why your Mac keeps asking for permissions, and make them stick (command line and background recorder) |
| [sticky-app](https://github.com/amansriven/Sticky) | Cask | The Sticky Mac app. Installs `sticky` too. Not notarized yet: the first launch needs **Open Anyway** in System Settings → Privacy & Security. |
